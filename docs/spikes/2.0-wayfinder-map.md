## Destination

Six locked, agent-executable specs plus the order and blocking between them, for everything that ships between 1.18 and the 2.0 milestone: model support (Fable 5.1, GPT-6 Astra), Nx monorepo, CI/CD with automatic npm publish and GitHub releases, Tokenmaxx many-to-many accounts, dashboard redesign, chaching.fyi landing page, and web themes. Nothing is executed inside this map; each spec hands off to `/wave` or a plan session.

## Notes

- **Order** (user's decree): models → monorepo → CI/CD → Tokenmaxx → dashboard → landing page → **theming dead last**, shipped as one PR on a branch so Rennet (rbutera/rennet) can review it.
- **2.0 is a milestone, not a big-bang.** Models, monorepo and CI/CD ship as 1.x. Landing page goes live with 2.0.
- **Solo maintainer plus agents.** Tickets sized for one 100K session; specs written so `/wave` can eat them.
- **Vocabulary** lives in `CONTEXT.md` at the repo root. Account = Subscription (one bill). Tokenmaxxed machine, Pool, Machine, Coverage, Theme are defined there.
- **Standing preferences decided while charting:** keep ALL personality copy (it is what sets chaching apart), no cost-honesty disclosure copy in the web UI (the null-never-zero data rule stays), kill the work/personal cutover concept entirely, receipt PNG always renders in the default theme, Register & Receipt stays the default web theme and bundled themes swap the whole palette including accent, TUI adopts the terminal's actual colours with no picker, transcripts stay the authoritative ledger and the existing upward-only Tokenmaxx reconcile is untouched, pre-Tokenmaxx history is left as-is with no mark, pnpm only (delete package-lock.json, add `packageManager`), one published npm package.
- **Copy from Rennet** wherever it fits: the zero-dep Nx cache proxy (`tools/nx-cache-proxy.mjs`) and its two CI steps, reusable `workflow_call` CI so release runs the identical gate, the "CI already green on this SHA" skip, draft-first release with retry and an `always()` outcome-assertion job, the pnpm supply-chain block, positive-control checks that fail if a gate passes bad input. Rennet has no npm publish, OIDC or version-bump precedent; those are designed fresh here.
- **Measured fact (2026-09-10, this machine):** transcripts alone are ~12% low by tokens against the Tokenmaxx proxy; with the 1.17 reconcile the per-day totals match exactly. Subagents ARE counted; the gap is background/internal model calls.
- Skills to consult per ticket: grilling + domain-modeling by default; `impeccable` and `prototype` for dashboard/theme tickets; `research` for research tickets; `claude-api` before any Anthropic pricing fact.
- Secrets (Cloudflare token, npm settings, Neon URL) never go in a ticket body.
